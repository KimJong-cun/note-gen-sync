# 外部中断

## 概述

外部中断是STM32处理外部事件的重要机制。与系统内部滴答定时器（HAL_Delay）不同，外部中断的时间信号来自外部世界，如按钮按下、传感器信号变化等。

## 配置步骤

### 1. GPIO配置

外部中断需要配置GPIO引脚，例如配置为EXTI12：

```c
GPIO_InitTypeDef GPIO_InitStruct = {0};

// 使能GPIO时钟
__HAL_RCC_GPIOX_CLK_ENABLE();

// 配置GPIO为输入模式
GPIO_InitStruct.Pin = GPIO_PIN_12;
GPIO_InitStruct.Mode = GPIO_MODE_IT_RISING;  // 上升沿触发
GPIO_InitStruct.Pull = GPIO_NOPULL;
HAL_GPIO_Init(GPIOX, &GPIO_InitStruct);
```

### 2. EXTI配置

外部中断通过EXTI（外部中断控制器）管理：

- 每个GPIO引脚都可以配置为外部中断源
- EXTI线通过GPIO与外部中断线连接
- 支持上升沿、下降沿或双边沿触发

## 中断处理逻辑

### 关键处理函数

```c
void HAL_GPIO_EXTI_IRQHandler(uint16_t GPIO_Pin)
```

**重要说明：** 为了防止中断重复执行，`HAL_GPIO_EXTI_IRQHandler`函数会：
1. 清除相应的中断挂起寄存器
2. 调用用户定义的回调函数

### 中断逻辑

### 回调函数

```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if(GPIO_Pin == PINx)
    {
        // 用户处理代码
        // 注意：不建议在回调函数中调用其他中断服务
    }
}
```

**注意事项：**
- 在中断回调函数中不推荐调用其他中断
- 回调函数应保持简短，避免复杂操作
- 避免在回调中使用阻塞函数

## 中断优先级

STM32中断优先级分为两个部分：

### 1. 抢占优先级（Preemption Priority）
- 高抢占优先级可以打断低抢占优先级的中断
- 数值越小，优先级越高

### 2. 响应优先级（Sub Priority / Response Priority）
- 当两个中断的抢占优先级相同时，响应优先级高的先执行
- 数值越小，优先级越高

### 优先级分组

```c
// 设置优先级分组
HAL_NVIC_SetPriorityGrouping(NVIC_PRIORITYGROUP_4);
// 4位抢占优先级，0位响应优先级

HAL_NVIC_SetPriorityGrouping(NVIC_PRIORITYGROUP_3);
// 3位抢占优先级，1位响应优先级

HAL_NVIC_SetPriorityGrouping(NVIC_PRIORITYGROUP_2);
// 2位抢占优先级，2位响应优先级

HAL_NVIC_SetPriorityGrouping(NVIC_PRIORITYGROUP_1);
// 1位抢占优先级，3位响应优先级

HAL_NVIC_SetPriorityGrouping(NVIC_PRIORITYGROUP_0);
// 0位抢占优先级，4位响应优先级
```

## 完整代码示例

```c
/* 1. GPIO和中断初始化 */
void EXTI_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    // 使能GPIO时钟
    __HAL_RCC_GPIOC_CLK_ENABLE();

    // 配置GPIO
    GPIO_InitStruct.Pin = GPIO_PIN_12;
    GPIO_InitStruct.Mode = GPIO_MODE_IT_FALLING;  // 下降沿触发
    GPIO_InitStruct.Pull = GPIO_PULLUP;           // 上拉电阻
    HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);

    // 配置NVIC
    HAL_NVIC_SetPriority(EXTI15_10_IRQn, 5, 0);
    HAL_NVIC_EnableIRQ(EXTI15_10_IRQn);
}

/* 2. 中断服务函数 */
void EXTI15_10_IRQHandler(void)
{
    HAL_GPIO_EXTI_IRQHandler(GPIO_PIN_12);
}

/* 3. 回调函数 */
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if(GPIO_Pin == GPIO_PIN_12)
    {
        // 处理外部中断
        // 例如：按键处理、外部信号检测等
        HandleExternalInterrupt();
    }
}

/* 4. 用户处理函数 */
void HandleExternalInterrupt(void)
{
    // 实际的应用逻辑
    // 注意保持简短高效
}
```

## 总结

1. **正确配置GPIO和EXTI**：确保GPIO模式设置为中断模式
2. **理解中断处理流程**：HAL库会自动清除挂起位，用户只需实现回调
3. **合理设置优先级**：根据应用需求配置抢占和响应优先级
4. **保持回调函数简短**：避免在回调中执行耗时操作
5. **注意中断嵌套**：高优先级中断可以打断低优先级中断
