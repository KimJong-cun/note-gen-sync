# 顺序表

## 1. 顺序表的定义

顺序表是用一组地址连续的存储单元依次存储数据元素的线性结构。

### 数学表示
- L = (a₁, a₂, a₃, ... , aₙ)
- 其中aᵢ是aᵢ₊₁的直接前驱，aᵢ₊₁是aᵢ的直接后继
- 是一个有限序列

### 特点
- 逻辑上相邻的元素，物理上也相邻
- 首节点无前驱，尾节点无后驱

## 2. 基本操作

| 操作名称 | 功能描述 | 时间复杂度 |
|---------|---------|-----------|
| 初始化 | 创建一个空的顺序表 | O(1) |
| 求表长 | 返回顺序表中元素个数 | O(1) |
| 取元素 | 获取第i个位置的元素 | O(1) |
| 查找元素 | 查找值为x的元素位置 | O(n) |
| 插入元素 | 在第i个位置插入元素 | O(n) |
| 删除元素 | 删除第i个位置的元素 | O(n) |

## 3. 数组存储结构

数组下标对应关系：

| 下标 | 元素 | 内存地址 |
|------|------|----------|
| 0 | a₁ | loc(A) |
| 1 | a₂ | loc(A) + sizeof(ElemType) |
| 2 | a₃ | loc(A) + 2 × sizeof(ElemType) |
| ... | ... | ... |
| i | aᵢ₊₁ | loc(A) + i × sizeof(ElemType) |
| ... | ... | ... |
| n-1 | aₙ | loc(A) + (n-1) × sizeof(ElemType) |

其中：
- `loc(A)` 是数组的首地址
- `sizeof(ElemType)` 是每个元素所占的字节数

## 4. 顺序表的类型定义

```c
#define MAXSIZE 100  // 默认最大容量

typedef struct {
    ElemType *data;      // 动态分配数组指针
    int length;          // 当前长度
    int capacity;       // 总容量
} SqList;
```

## 5. 基本操作的C语言实现

### 5.1 初始化操作
```c
// 动态分配数组
Status InitList(SqList &L) {
    L.data = (ElemType*)malloc(MAXSIZE * sizeof(ElemType));
    if (!L.data) return ERROR;
    L.length = 0;
    L.capacity = MAXSIZE;
    return OK;
}
```

### 5.2 插入操作
```c
// 在第i个位置插入元素e
Status ListInsert(SqList &L, int i, ElemType e) {
    // 判断插入位置是否合法
    if (i < 1 || i > L.length + 1) return ERROR;

    // 判断是否满表
    if (L.length >= L.capacity) return ERROR;

    // 后移元素
    for (int j = L.length; j >= i; j--) {
        L.data[j] = L.data[j - 1];
    }

    // 插入元素
    L.data[i - 1] = e;
    L.length++;
    return OK;
}
```

### 5.3 删除操作
```c
// 删除第i个位置的元素
Status ListDelete(SqList &L, int i, ElemType &e) {
    // 判断删除位置是否合法
    if (i < 1 || i > L.length) return ERROR;

    // 保存被删除元素
    e = L.data[i - 1];

    // 前移元素
    for (int j = i; j < L.length; j++) {
        L.data[j - 1] = L.data[j];
    }

    L.length--;
    return OK;
}
```

### 5.4 查找操作
```c
// 查找值为e的元素
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] == e) {
            return i + 1;  // 返回位置（从1开始）
        }
    }
    return 0;  // 未找到返回0
}
```

## 6. 顺序表的优缺点

### 优点
- 随机访问效率高（O(1)）
- 存储密度高，空间利用率好
- 逻辑相邻，物理相邻，实现简单

### 缺点
- 插入和删除操作需要移动大量元素（O(n)）
- 需要预先分配连续空间，容易造成空间浪费或溢出
- 长度变化较大时，空间分配不够灵活

## 7. 顺序表的应用场景

- 数据量固定或变化不大的场景
- 需要频繁随机访问的场景
- 内存资源充足的情况
