# 队列

## 队列的基本概念

队列是一种**只允许在一端插入，在另一端删除**的线性表。
初始值：front = 0
### 队列的特点

- **先进先出（FIFO）**：First In First Out
- **受限的线性表**：
  - 只允许在**队尾**插入元素
  - 只允许在**队头**删除元素

### 基本术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 队头 | Front | 允许删除的一端 |
| 队尾 | Rear | 允许插入的一端 |
| 入队 | EnQueue | 向队尾插入元素 |
| 出队 | DeQueue | 从队头删除元素 |
| 空队列 | Empty Queue | 队列中没有元素 |

## 队列的顺序存储结构

### 结构定义

```c
#define MAXSIZE 100  // 队列的最大容量

typedef struct {
    ElemType data[MAXSIZE];  // 存储队列元素的数组
    int front;               // 队头指针，指向队头元素
    int rear;                // 队尾指针，指向队尾元素的下一个位置
} SqQueue;
```

### 指针说明

```
队列：a, b, c

索引：   0    1    2    3
      ┌───┬───┬───┬───┐
      │ a │ b │ c │   │
      └───┴───┴───┴───┘
       ↑           ↑
      front       rear
```

**关键点**：
- `front`：指向队头元素
- `rear`：指向队尾元素的**下一个位置**
- 初始时：`front = 0, rear = 0`（空队列）

## 队列的"假溢出"问题

### 问题演示

```
入队 a, b, c, d, e 后：
索引：   0    1    2    3    4
      ┌───┬───┬───┬───┬───┐
      │ a │ b │ c │ d │ e │
      └───┴───┴───┴───┴───┘
       ↑                   ↑
      front               rear

出队 a, b, c 后：
索引：   0    1    2    3    4
      ┌───┬───┬───┬───┬───┐
      │   │   │   │ d │ e │
      └───┴───┴───┴───┴───┘
                   ↑       ↑
                  rear    front

入队 f 时：rear == MAXSIZE，队列"满"了
但前面有空位！这就是"假溢出"
```

## 解决方案：循环队列

### 循环队列示意图

```
      ┌─────────────────────┐
      │                     ↓
   0  │ a   b   c   d   e   │
      └─────────────────────┘
      ↑                     ↑
     rear                  front

rear继续向后会回到0，形成循环
```

### 判断条件

| 方法 | 队空条件 | 队满条件 | 说明 |
|------|---------|---------|------|
| **方法1：牺牲一个空间** | front == rear | (rear + 1) % MAXSIZE == front | 经典方法，少用一个空间 |
| **方法2：增加计数器** | size == 0 | size == MAXSIZE | 推荐！不浪费空间，逻辑清晰 |

### 方法1：牺牲一个空间

```c
// 判断队空
int QueueEmpty(SqQueue Q) {
    return Q.front == Q.rear;
}

// 判断队满
int QueueFull(SqQueue Q) {
    return (Q.rear + 1) % MAXSIZE == Q.front;
}

// 入队
Status EnQueue(SqQueue *Q, ElemType e) {
    // 判断队满
    if ((Q->rear + 1) % MAXSIZE == Q->front)
        return ERROR;

    // 元素入队
    Q->data[Q->rear] = e;

    // rear循环后移
    Q->rear = (Q->rear + 1) % MAXSIZE;

    return OK;
}

// 出队
Status DeQueue(SqQueue *Q, ElemType *e) {
    // 判断队空
    if (Q->front == Q->rear)
        return ERROR;

    // 取出队头元素
    *e = Q->data[Q->front];

    // front循环后移
    Q->front = (Q->front + 1) % MAXSIZE;

    return OK;
}
```

### 方法2：增加计数器（推荐）

```c
typedef struct {
    ElemType data[MAXSIZE];
    int front;
    int rear;
    int size;  // 队列中元素个数
} SqQueue;

// 初始化
void InitQueue(SqQueue *Q) {
    Q->front = 0;
    Q->rear = 0;
    Q->size = 0;
}

// 判断队空
int QueueEmpty(SqQueue Q) {
    return Q.size == 0;
}

// 判断队满
int QueueFull(SqQueue Q) {
    return Q.size == MAXSIZE;
}

// 入队
Status EnQueue(SqQueue *Q, ElemType e) {
    if (Q->size == MAXSIZE)  // 队满
        return ERROR;

    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAXSIZE;
    Q->size++;  // 计数器加1

    return OK;
}

// 出队
Status DeQueue(SqQueue *Q, ElemType *e) {
    if (Q->size == 0)  // 队空
        return ERROR;

    *e = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    Q->size--;  // 计数器减1

    return OK;
}

// 获取队列长度
int QueueLength(SqQueue Q) {
    return Q.size;  // 直接返回
}
```

## 队列的链式存储结构

### 链队列节点定义

```c
typedef struct QNode {
    ElemType data;
    struct QNode *next;
} QNode, *QueuePtr;

typedef struct {
    QueuePtr front;  // 队头指针
    QueuePtr rear;   // 队尾指针
} LinkQueue;
```

### 链队列示意图

```
                 队头              队尾
                  ↓                 ↓
    ┌────────┐   ┌───┐   ┌───┐   ┌───┐
    │  Q     │ → │ a │ → │ b │ → │ c │ → NULL
    └────────┘   └───┘   └───┘   └───┘
      ↑front    ↑rear
```

### 链队列的基本操作

#### 初始化链队列

```c
Status InitQueue(LinkQueue *Q) {
    Q->front = Q->rear = (QueuePtr)malloc(sizeof(QNode));
    if (!Q->front) return ERROR;
    Q->front->next = NULL;
    return OK;
}
```

#### 判断队空

```c
int QueueEmpty(LinkQueue Q) {
    return Q.front == Q.rear;
}
```

#### 入队

```c
Status EnQueue(LinkQueue *Q, ElemType e) {
    // 创建新节点
    QueuePtr p = (QueuePtr)malloc(sizeof(QNode));
    if (!p) return ERROR;

    p->data = e;
    p->next = NULL;

    // 新节点插入队尾
    Q->rear->next = p;

    // 修改队尾指针
    Q->rear = p;

    return OK;
}
```

#### 出队

```c
Status DeQueue(LinkQueue *Q, ElemType *e) {
    // 判断队空
    if (Q->front == Q->rear)
        return ERROR;

    // 保存队头节点
    QueuePtr p = Q->front->next;

    // 取出数据
    *e = p->data;

    // 修改队头指针
    Q->front->next = p->next;

    // 如果队列只有一个元素，出队后为空
    if (Q->rear == p)
        Q->rear = Q->front;

    // 释放节点
    free(p);

    return OK;
}
```

## 顺序队列 vs 链队列

| 特性 | 顺序队列（循环） | 链队列 |
|------|----------------|--------|
| 存储方式 | 连续存储 | 离散存储 |
| 空间分配 | 静态分配（固定大小） | 动态分配（按需申请） |
| 空间利用率 | 可能浪费一个单元 | 不浪费，但每节点需要指针 |
| 实现复杂度 | 需要处理循环 | 较简单 |
| 适用场景 | 最大容量已知 | 容量不确定 |

## 队列的应用场景

### 1. 操作系统进程调度
- 就绪队列：等待执行的进程
- 打印队列：等待打印的任务

### 2. 网络请求处理
- 服务器请求队列
- 消息队列

### 3. 缓冲区
- 键盘输入缓冲区
- 网络数据缓冲区

### 4. 层次遍历
- 二叉树的层序遍历
- 图的广度优先搜索（BFS）

### 5. 实际应用示例

```c
// 打印任务队列
typedef struct {
    char documentName[100];
    int priority;
} PrintJob;

void PrintQueueDemo() {
    LinkQueue Q;
    InitQueue(&Q);

    // 添加打印任务
    PrintJob job1 = {"文档1.pdf", 1};
    PrintJob job2 = {"文档2.doc", 2};
    PrintJob job3 = {"文档3.txt", 1};

    EnQueue(&Q, job1);
    EnQueue(&Q, job2);
    EnQueue(&Q, job3);

    // 按顺序处理打印任务
    PrintJob currentJob;
    while (!QueueEmpty(Q)) {
        DeQueue(&Q, &currentJob);
        printf("正在打印: %s\n", currentJob.documentName);
    }
}
```

## 时间复杂度总结

| 操作 | 顺序队列 | 链队列 |
|------|---------|--------|
| 初始化 | O(1) | O(1) |
| 判空 | O(1) | O(1) |
| 入队 | O(1) | O(1) |
| 出队 | O(1) | O(1) |
| 获取队头 | O(1) | O(1) |

所有操作的时间复杂度都是 O(1)，这是队列的重要特性。
