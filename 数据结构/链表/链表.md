# 链表

## 链表的基本概念

链表是一种物理存储单元上非连续、非顺序的存储结构，数据元素的逻辑顺序是通过链表中的指针链接次序实现的。

### 节点结构
每个节点包含两个部分：
- **数据域（data）**：存储数据元素
- **指针域（next）**：存储下一个节点的地址

### 单链表节点定义
```c
typedef struct LNode {
    ElemType data;       // 数据域
    struct LNode *next;   // 指针域，指向下一个节点
} LNode, *LinkList;
```

### 链表与顺序存储对比

| 特性 | 链式存储 | 顺序存储 |
|------|----------|----------|
| 存储方式 | 分散存储 | 连续存储 |
| 地址关系 | 逻辑相邻，物理相邻 | 逻辑相邻，物理相邻 |
| 随机访问 | O(n) | O(1) |
| 插入删除 | O(1) | O(n) |
| 空间效率 | 较低（需额外指针） | 较高（紧凑存储） |
| 内存分配 | 动态分配 | 预分配 |
| 空间浪费 | 小 | 大（固定分配） |

### 链表的特点
- 链表中的节点在内存中不一定是连续的
- 通过指针建立节点之间的逻辑关系
- 可以动态调整大小
- 插入和删除操作效率高

## 基本操作实现

### 1. 按序号查找

```c
// 查找第i个节点，成功返回节点指针，失败返回NULL
LNode *GetElem(LinkList L, int i) {
    int j = 1;
    LNode *p = L->next;
    if (i == 0) return L;
    if (i < 0) return NULL;
    while (p && j < i) {
        p = p->next;
        j++;
    }
    return p;
}
```

**执行过程示例**（查找第3个节点，i=3）：

| 循环次数 | j值 | j < i? | p指向 | 操作 |
|---------|-----|-------|-------|------|
| 初始 | 1 | 1<3 ✓ | 第1个节点 | - |
| 第1次 | 1→2 | 2<3 ✓ | 第2个节点 | p后移 |
| 第2次 | 2→3 | 3<3 ✗ | 第3个节点 | p后移，退出 |

### 2. 按值查找

```c
// 查找值为e的节点，成功返回节点指针，失败返回NULL
LNode *LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;
    while (p != NULL && p->data != e) {
        p = p->next;
    }
    return p;
}
```

### 3. 插入操作

```c
// 在第i个位置插入元素e
Status ListInsert(LinkList L, int i, ElemType e) {
    int j = 0;
    LNode *p = L;
    // 找到第i-1个节点
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }
    // 位置不合法
    if (p == NULL || j > i - 1) return ERROR;

    // 创建新节点
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;
    p->next = s;
    return OK;
}
```

### 4. 删除操作

```c
// 删除第i个位置的元素，并用e返回其值
Status ListDelete(LinkList L, int i, ElemType &e) {
    int j = 0;
    LNode *p = L;
    // 找到第i-1个节点
    while (p->next != NULL && j < i - 1) {
        p = p->next;
        j++;
    }
    // 位置不合法或表为空
    if (p->next == NULL || j > i - 1) return ERROR;

    LNode *q = p->next;
    e = q->data;
    p->next = q->next;
    free(q);
    return OK;
}
```

### 5. 初始化链表

```c
// 初始化一个带头结点的空链表
Status InitList(LinkList &L) {
    L = (LNode*)malloc(sizeof(LNode));
    if (!L) return ERROR;
    L->next = NULL;
    return OK;
}
```

### 6. 销毁链表

```c
// 销毁链表，释放所有节点
void DestroyList(LinkList &L) {
    LNode *p = L;
    LNode *q;
    while (p != NULL) {
        q = p;
        p = p->next;
        free(q);
    }
}
```

## 链表的类型

### 1. 单链表
- 每个节点只有一个指向下一个节点的指针
- 只能从头到尾单向遍历

### 2. 双链表
```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior;
    struct DNode *next;
} DNode, *DLinkList;
```

### 3. 循环链表
- 最后一个节点的next指针指向头节点
- 形成一个环状结构

## 链表的应用场景

### 适用场景
- 数据量变化频繁
- 频繁插入删除操作
- 内存空间受限
- 需要动态调整大小的数据结构

### 不适用场景
- 需要频繁随机访问
- 数据量固定且较小
- 对空间要求严格
