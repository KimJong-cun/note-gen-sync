# 栈

## 栈的基本概念

栈是一种**只能在一端进行插入或删除操作**的线性表。

### 栈的特点

- **受限的线性表**：只允许在一端（栈顶）进行插入和删除
- **先进后出（LIFO）**：Last In First Out
- **后进先出**：最后进入的元素最先被取出

### 基本术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 栈顶 | Top | 允许插入和删除的一端 |
| 栈底 | Bottom | 固定不动的一端 |
| 进栈/入栈 | Push | 向栈顶插入元素 |
| 出栈/退栈 | Pop | 从栈顶删除元素 |
| 空栈 | Empty Stack | 栈中没有元素 |

## 栈的顺序存储结构

### 结构定义

```c
#define MAXSIZE 100  // 栈的最大容量

typedef struct {
    ElemType data[MAXSIZE];  // 存储栈元素的数组
    int top;                 // 栈顶指针，指向栈顶元素
} SqStack;
```

### 栈顶指针说明

```
栈的状态        data[0]  data[1]  data[2]  data[3]    top值
─────────────────────────────────────────────────────────
空栈            -        -        -        -         -1
─────────────────────────────────────────────────────────
元素A进栈       A        -        -        -          0
─────────────────────────────────────────────────────────
元素B进栈       A        B        -        -          1
─────────────────────────────────────────────────────────
元素C进栈       A        B        C        -          2
─────────────────────────────────────────────────────────
元素C出栈       A        B        -        -          1
```

**关键点**：
- `top = -1`：表示空栈
- `top = 0`：栈中有1个元素（data[0]）
- `top = MAXSIZE - 1`：栈满

## 基本操作实现

### 1. 初始化栈

```c
// 初始化一个空栈
Status InitStack(SqStack *S) {
    S->top = -1;  // 栈顶指针指向-1，表示空栈
    return OK;
}
```

### 2. 判断栈是否为空

```c
// 如果栈为空返回TRUE，否则返回FALSE
Status StackEmpty(SqStack S) {
    if (S.top == -1)
        return TRUE;
    else
        return FALSE;
}
```

### 3. 进栈操作

```c
// 将元素e压入栈顶
Status Push(SqStack *S, ElemType e) {
    // 先判断栈是否已满
    if (S->top == MAXSIZE - 1) {
        return ERROR;  // 栈满，无法进栈
    }

    // 栈顶指针先加1
    S->top++;

    // 再将元素放入栈顶位置
    S->data[S->top] = e;

    return OK;
}
```

**进栈流程**：
1. 检查栈是否已满（`top == MAXSIZE - 1`）
2. 栈顶指针加1（`top++`）
3. 新元素放入栈顶位置

### 4. 出栈操作

```c
// 从栈顶弹出元素，用e返回其值
Status Pop(SqStack *S, ElemType *e) {
    // 先判断栈是否为空
    if (S->top == -1) {
        return ERROR;  // 栈空，无法出栈
    }

    // 先取出栈顶元素
    *e = S->data[S->top];

    // 栈顶指针减1
    S->top--;

    return OK;
}
```

**出栈流程**：
1. 检查栈是否为空（`top == -1`）
2. 取出栈顶元素
3. 栈顶指针减1（`top--`）

### 5. 读取栈顶元素

```c
// 读取栈顶元素，但不删除
Status GetTop(SqStack S, ElemType *e) {
    if (S.top == -1)
        return ERROR;  // 栈空

    *e = S.data[S.top];  // 返回栈顶元素
    return OK;
}
```

## 栈的链式存储结构

### 链栈节点定义

```c
typedef struct StackNode {
    ElemType data;              // 数据域
    struct StackNode *next;     // 指针域
} StackNode, *LinkStack;
```

### 链栈示意图

```
      栈顶                   栈底
       ↓                      ↓
    ┌───┐    ┌───┐    ┌───┐
    │ C │ ─→│ B │ ─→│ A │ ─→ NULL
    └───┘    └───┘    └───┘
     top
```

**特点**：
- 栈顶在链表头部
- 栈底在链表尾部
- 不需要头节点

### 链栈的基本操作

#### 初始化链栈

```c
// 初始化一个空栈
Status InitStack(LinkStack *S) {
    *S = NULL;  // 栈顶指针置空
    return OK;
}
```

#### 判断链栈是否为空

```c
Status StackEmpty(LinkStack S) {
    if (S == NULL)
        return TRUE;
    else
        return FALSE;
}
```

#### 进栈

```c
// 将元素e压入栈顶
Status Push(LinkStack *S, ElemType e) {
    // 创建新节点
    StackNode *p = (StackNode*)malloc(sizeof(StackNode));
    if (!p) return ERROR;

    // 填充数据
    p->data = e;

    // 新节点指向原栈顶
    p->next = *S;

    // 栈顶指针指向新节点
    *S = p;

    return OK;
}
```

#### 出栈

```c
// 从栈顶弹出元素
Status Pop(LinkStack *S, ElemType *e) {
    if (*S == NULL)
        return ERROR;  // 栈空

    // 保存栈顶节点
    StackNode *p = *S;

    // 取出数据
    *e = p->data;

    // 栈顶指针后移
    *S = p->next;

    // 释放原栈顶节点
    free(p);

    return OK;
}
```

## 顺序栈 vs 链栈

| 特性 | 顺序栈 | 链栈 |
|------|--------|------|
| 存储方式 | 连续存储 | 离散存储 |
| 空间分配 | 静态分配（固定大小） | 动态分配（按需申请） |
| 空间利用率 | 可能溢出或浪费 | 不会溢出，但每节点需要指针空间 |
| 实现复杂度 | 简单 | 稍复杂 |
| 适用场景 | 最大容量已知 | 容量不确定 |

## 栈的应用场景

### 1. 函数调用栈
- 保存函数返回地址
- 保存局部变量
- 递归调用

### 2. 括号匹配
```c
// 检查表达式中的括号是否匹配
void BracketMatch(char *str) {
    SqStack S;
    InitStack(&S);

    for (int i = 0; str[i] != '\0'; i++) {
        if (str[i] == '(' || str[i] == '[' || str[i] == '{') {
            Push(&S, str[i]);  // 左括号进栈
        } else if (str[i] == ')' || str[i] == ']' || str[i] == '}') {
            if (StackEmpty(S)) {
                printf("括号不匹配！\n");
                return;
            }
            Pop(&S, &str[i]);  // 右括号出栈匹配
        }
    }

    if (StackEmpty(S))
        printf("括号匹配！\n");
    else
        printf("括号不匹配！\n");
}
```

### 3. 表达式求值
- 中缀表达式转后缀表达式
- 后缀表达式求值

### 4. 浏览器后退功能
- 保存访问历史
- 后退时出栈

### 5. 编辑器撤销功能
- 保存操作历史
- 撤销时出栈恢复

## 时间复杂度总结

| 操作 | 顺序栈 | 链栈 |
|------|--------|------|
| 初始化 | O(1) | O(1) |
| 判空 | O(1) | O(1) |
| 进栈 | O(1) | O(1) |
| 出栈 | O(1) | O(1) |
| 取栈顶 | O(1) | O(1) |

所有操作的时间复杂度都是 O(1)，这是栈的重要特性。
